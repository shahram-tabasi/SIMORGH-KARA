# راهنمای اتصال ساعت هوشمند QCY و دستگاه‌های بلوتوثی

## overview

سیمرغ‌کارا از **سه روش** برای دریافت تردد پشتیبانی می‌کند:

1. **ترمینال سخت‌افزاری** (ZKTeco/Hikvision/Suprema) → از طریق Device Bridge
2. **اپ نگهبان** (تشخیص چهره با گوشی) → اپ نیتیو اندروید
3. **اپ معدن** (عکس + GPS روی گوشی کارمند) → اپ نیتیو اندروید

ساعت‌های هوشمند مانند **QCY** یا سایر گجت‌های بلوتوثی به‌صورت مستقیم به سیمرغ‌کارا وصل **نمی‌شوند**، مگر اینکه:
- ساعت دارای **SIM مستقل** و قابلیت اجرای اپلیکیشن باشد (مانند WearOS)
- یا از طریق **گوشی جفت‌شده** به‌عنوان واسط عمل کند

---

## روش‌های ممکن برای ساعت QCY

### روش ۱: استفاده از گوشی به‌عنوان واسط (توصیه‌شده)

اگر ساعت QCY شما فقط بلوتوثی است و SIM ندارد:

1. **اپ سیمرغ‌کارا را روی گوشی نصب کنید** (اندروید/iOS)
2. گوشی را در حالت **قفل‌شده** همراه داشته باشید
3. هنگام ورود/خروج:
   - گوشی را از قفل باز کنید
   - دکمهٔ «ثبت ورود» یا «ثبت خروج» را بزنید
   - optionally عکس سلفی بگیرید
   - GPS خودکار ثبت می‌شود

**مزایا:**
- نیاز به سخت‌افزار اضافی نیست
- GPS دقیق دارد
- عکس پرسنل ثبت می‌شود

**معایب:**
- باید گوشی همراه باشد

---

### روش ۲: ساخت اپ اختصاصی برای ساعت‌های WearOS

اگر ساعت شما **WearOS** دارد (نه QCY معمولی):

1. یک اپلیکیشن ساده WearOS بسازید که:
   - دکمهٔ «ورود» و «خروج» دارد
   - به API سیمرغ‌کارا وصل می‌شود
   - توکن دستگاه را ذخیره می‌کند

2. API مورد استفاده:
   ```
   POST /api/{slug}/attendance/ingest
   Authorization: Bearer {device-token}
   Content-Type: application/json
   
   {
     "email": "user@company.com",
     "kind": "in",  // یا "out"
     "at": "2026-01-15T08:00:00Z",  // اختیاری
     "lat": 35.6892,  // اختیاری - اگر GPS دارد
     "lng": 51.3890
   }
   ```

3. توکن دستگاه را از دیتابیس بگیرید:
   ```sql
   INSERT INTO tenant_{schema}.attendance_devices 
   (name, token, kind, is_active)
   VALUES 
   ('QCY Watch', 'random-secure-token', 'mobile', true);
   ```

---

### روش ۳: استفاده از NFC Tag (ارزان و عملی)

اگر ساعت NFC دارد اما اپ اجرا نمی‌کند:

1. **NFC Tag** های ارزان قیمت بخرید
2. هر تگ را به یک کاربر نسبت دهید:
   ```sql
   -- در جدول members فیلد nfc_tag_id اضافه کنید
   ALTER TABLE members ADD COLUMN nfc_tag_id text UNIQUE;
   UPDATE members SET nfc_tag_id = 'tag-serial-number' WHERE email = 'user@co.ir';
   ```

3. یک **گوشی قدیمی** دمِ درب بگذارید با:
   - اپ سیمرغ‌کارا باز
   - NFC روشن
   - حالت کیوسک

4. کاربر ساعت را به گوشی نزدیک می‌کند → تردد ثبت می‌شود

## دریافت توکن دستگاه

برای هر دستگاه (گوشی، ساعت، ترمینال) یک توکن منحصر‌به‌فرد لازم است:

```sql
-- به دیتابیس وصل شوید
psql $DATABASE_URL

-- توکن جدید برای گوشی/ساعت
INSERT INTO tenant_{your_schema}.attendance_devices 
  (name, token, kind, is_active)
VALUES 
  ('QCY Smart Watch', 'qcy-' || encode(gen_random_bytes(16), 'hex'), 'mobile', true);

-- توکن را کپی کنید و در اپ وارد نمایید
SELECT token FROM tenant_{your_schema}.attendance_devices 
WHERE name = 'QCY Smart Watch';
```

## محدودیت‌های ساعت‌های QCY معمولی

ساعت‌های QCY معمولی (غیر از مدل‌های WearOS):
- ❌ سیستم عامل کامل ندارند
- ❌ نمی‌توان اپ سفارشی نصب کرد
- ❌ GPS مستقل ندارند (از گوشی می‌گیرند)
- ❌ WiFi/LTE ندارند

**راه‌حل:** از گوشی به‌عنوان واسط استفاده کنید یا یک گوشی قدیمی دمِ درب بگذارید.

---

## راه‌حل پیشنهادی برای شرکت شما

با توجه به اینکه گفتید «گوشی QCY است» ولی در واقع ساعت است:

### گزینهٔ عملی و کم‌هزینه:

1. **یک گوشی اندروید قدیمی** تهیه کنید (حتی ارزان‌قیمت)
2. آن را دمِ درب شرکت قرار دهید
3. اپ سیمرغ‌کارا را نصب کنید (یا وب‌اپ PWA)
4. حالت کیوسک فعال کنید تا همیشه باز بماند
5. کارمندان با زدن دکمهٔ «ورود/خروج» ترددشان ثبت شود

**هزینه:** حدود ۲-۳ میلیون تومان برای گوشی دست‌دوم

### گزینهٔ حرفه‌ای:

1. **ترمینال تشخیص چهره** بخرید (ZKTeco SpeedFace یا مشابه)
2. به شبکه شرکت وصل کنید
3. Device Bridge را روی یک سرور کوچک اجرا کنید
4. تردد خودکار بدون تماس ثبت می‌شود

**هزینه:** حدود ۵-۱۰ میلیون تومان برای ترمینال

## سوالات متداول

### آیا می‌توان مستقیماً از ساعت استفاده کرد؟
فقط اگر WearOS داشته باشد و بتوان اپ سفارشی نصب کرد.

### آیا GPS ساعت کافی است؟
اغلب ساعت‌ها GPS داخلی ندارند و از گوشی می‌گیرند.

### بهترین راه‌حل چیست؟
گوشی دمِ درب + ثبت با دکمه (ارزان) یا ترمینال تشخیص چهره (حرفه‌ای).

### چگونه بفهمیم ساعت WearOS دارد؟
به تنظیمات ساعت بروید → About → اگر WearOS دیدید، قابل استفاده است.

## کد نمونه اپ ساده اندروید (Kotlin)

اگر می‌خواهید اپ ساده‌ای برای گوشی دمِ درب بسازید:

```kotlin
// MainActivity.kt
class MainActivity : AppCompatActivity() {
    private val apiUrl = "https://app.simorgh.ir/api/{slug}/attendance/ingest"
    private val deviceToken = "qcy-abc123..."
    
    fun registerAttendance(email: String, kind: String) {
        lifecycleScope.launch {
            val response = HttpClient().post(apiUrl) {
                headers.append("Authorization", "Bearer $deviceToken")
                headers.append("Content-Type", "application/json")
                setBody("""
                    {"email":"$email","kind":"$kind"}
                """.trimIndent())
            }
            
            if (response.status.isSuccess) {
                showToast("تردد با موفقیت ثبت شد")
            }
        }
    }
}
```
