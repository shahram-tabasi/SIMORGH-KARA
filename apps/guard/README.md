# اپ نگهبان (Flutter)

اپ تبلت/گوشی برای **نگهبان دمِ درب**: ثبت ورود/خروج افراد همراه با **تصویر چهره**.
از Google ML Kit برای **تشخیص حضور چهره** در تصویر استفاده می‌کند و تردد را به
`POST /api/<slug>/attendance/ingest` (با `source='guard'` + عکس) می‌فرستد.

## جریان کار
1. کارگزینی یک دستگاه از نوع **«اپ نگهبان»** می‌سازد و توکن می‌دهد.
2. نگهبان در تنظیمات: آدرس سرور، slug، توکن را وارد می‌کند.
3. برای هر نفر: ایمیل/کد فرد را وارد می‌کند → دکمهٔ «ورود/خروج + چهره» → دوربین
   باز می‌شود، عکس گرفته و حضور چهره تأیید می‌شود → تردد ثبت می‌شود.

## ساخت و اجرا
نیازمند Flutter SDK (روی دستگاه خودتان):
```bash
cd apps/guard
flutter pub get
flutter run            # یا flutter build apk --release
```
مجوزها در `AndroidManifest.xml`: `INTERNET`, `CAMERA`.

## دربارهٔ «تشخیص خودکار چهره» (هویت‌سنجی)
نسخهٔ فعلی **حضور چهره** را تشخیص می‌دهد ولی هویت را خودکار تعیین نمی‌کند؛
نگهبان فرد را انتخاب می‌کند. برای **شناسایی خودکار (این چه کسی است؟)** نیاز است:
- **ثبت چهرهٔ اولیه (enrollment)** هر کارمند و استخراج بردار ویژگی (embedding) با
  مدلی مثل FaceNet/MobileFaceNet.
- مقایسهٔ بردار چهرهٔ گرفته‌شده با بردارهای ثبت‌شده (cosine similarity).
- این یک فاز ML جداگانه است؛ ساختار اپ آماده افزودن آن است.

> این یک **اسکلت آماده** است؛ روی دستگاه واقعی build/تست شود.
