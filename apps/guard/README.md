# اپ نگهبان (Flutter)

اپ تبلت/گوشی برای **نگهبان دمِ درب**: ثبت ورود/خروج افراد همراه با **تصویر چهره**.
از Google ML Kit برای **تشخیص حضور چهره** در تصویر استفاده می‌کند و تردد را به
`POST /api/<slug>/attendance/ingest` (با `source='guard'` + عکس) می‌فرستد.

## جریان کار
1. کارگزینی یک دستگاه از نوع **«اپ نگهبان»** می‌سازد و توکن می‌دهد.
2. نگهبان در تنظیمات: آدرس سرور، slug، توکن را وارد می‌کند.
3. برای هر نفر: ایمیل/کد فرد را وارد می‌کند → دکمهٔ «ورود/خروج + چهره» → دوربین
   باز می‌شود، عکس گرفته و حضور چهره تأیید می‌شود → تردد ثبت می‌شود.

## ساخت و اجرا
نیازمند Flutter SDK (روی دستگاه خودتان):
```bash
cd apps/guard
flutter pub get
flutter run            # یا flutter build apk --release
```
مجوزها در `AndroidManifest.xml`: `INTERNET`, `CAMERA`.

## تشخیص خودکار چهره (هویت‌سنجی) ✅

اپ حالا **هویت‌سنجی خودکار** دارد:
- **ثبت چهرهٔ اولیه**: ایمیل فرد را وارد کنید → «ثبت چهره» → بردار چهره روی دستگاه
  (TFLite/MobileFaceNet) محاسبه و به `/attendance/face/enroll` ارسال می‌شود.
- **تشخیص**: «ورود/خروج (چهره)» → عکس → بردار → `/attendance/face/identify` →
  سرور با شباهت کسینوسی (آستانهٔ ۰.۶۲) فرد را می‌شناسد و تردد را خودکار ثبت می‌کند.

سمت سرور (محاسبهٔ شباهت + ذخیرهٔ بردار) **ساخته و تست شده** است. سمت دستگاه:

### افزودن مدل embedding (لازم)
فایل `assets/mobilefacenet.tflite` (مدل MobileFaceNet، خروجی ۱۹۲/۱۲۸ بُعدی) را
کنار اپ قرار دهید. در `pubspec.yaml` به‌عنوان asset ثبت شده است.

> برای دقت بالاتر، پیش از embedding، چهرهٔ تشخیص‌داده‌شده crop/align شود.
> این یک **اسکلت آماده** است؛ روی دستگاه واقعی با مدل واقعی build/تست شود.
