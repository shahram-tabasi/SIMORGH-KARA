# QCy Bridge - اپلیکیشن اندروید برای اتصال ساعت‌های QCY به سیمرغ‌کارا

## 📱 معرفی
این اپلیکیشن داده‌های سلامت را از ساعت‌های هوشمند QCY خوانده و از طریق WiFi به سرور سیمرغ‌کارا ارسال می‌کند.

## 🔧 پیش‌نیازها
- Android Studio Arctic Fox یا جدیدتر
- حداقل SDK: 26 (Android 8.0)
- هدف SDK: 34 (Android 14)
- دستگاه اندرویدی با پشتیبانی از Bluetooth LE

## 🚀 راه‌اندازی

### ۱. باز کردن پروژه در Android Studio
```bash
cd qcy-bridge-app
# پروژه را در Android Studio باز کنید
```

### ۲. تنظیم فایل کانفیگ
فایل `qcy-bridge.yml` را در ریشه پروژه کپی کرده و مقادیر زیر را تنظیم کنید:
- `base_url`: آدرس سرور سیمرغ‌کارا
- `device_token`: توکن احراز هویت دستگاه (از پنل ادمین بگیرید)

### ۳. ساخت APK
در Android Studio:
1. منوی Build → Build Bundle(s) / APK(s) → Build APK(s)
2. فایل APK در `app/build/outputs/apk/debug/` ساخته می‌شود

## 📡 نحوه کار

### اتصال به ساعت QCY
1. بلوتوث گوشی را روشن کنید
2. برنامه را اجرا کنید
3. کد پرسنلی خود را وارد کنید
4. دکمه "جستجوی دستگاه QCY" را بزنید
5. پس از یافتن ساعت، اتصال برقرار می‌شود

### دریافت داده‌های سلامت
برنامه به صورت خودکار داده‌های زیر را از ساعت می‌خواند:
- ضربان قلب (Heart Rate)
- درصد اکسیژن خون (SpO2)
- دمای بدن (Temperature)
- تعداد گام‌ها (Steps)
- درصد باتری ساعت

### ارسال به سرور
1. دکمه "دریافت موقعیت فعلی" را بزنید
2. دکمه "ارسال داده به سرور" را بزنید
3. داده‌ها به API سیمرغ‌کارا ارسال می‌شوند

## ⚠️ نکات مهم

### UUIDهای بلوتوث
هر مدل ساعت QCY UUIDهای مخصوص به خود را دارد. برای پیدا کردن UUIDهای مدل خود:
1. برنامه را اجرا کنید
2. به Logcat نگاه کنید
3. سرویس‌ها و کاراکتریستیک‌های نمایش داده شده را یادداشت کنید
4. UUIDهای مربوط به ضربان قلب و اکسیژن را در کد جایگزین کنید

### مجوزها
برنامه نیاز به مجوزهای زیر دارد:
- بلوتوث (Bluetooth Connect/Scan)
- موقعیت مکانی (Location)
- اینترنت

### حالت تولید
برای استفاده در محیط واقعی:
1. توکن دستگاه را از پنل ادمین بگیرید
2. آدرس سرور را به HTTPS تغییر دهید
3. APK را با امضای Release بسازید

## 🛠 عیب‌یابی

### دستگاه یافت نمی‌شود
- مطمئن شوید بلوتوث گوشی روشن است
- ساعت را در حالت جفت‌سازی قرار دهید
- فاصله گوشی و ساعت را کم کنید

### داده‌ها نمایش داده نمی‌شوند
- UUIDهای بلوتوث را بررسی کنید
- لاگ‌های Logcat را چک کنید
- مدل ساعت خود را بررسی کنید

### خطا در ارسال به سرور
- اتصال اینترنت را بررسی کنید
- توکن دستگاه را تأیید کنید
- آدرس سرور را بررسی کنید
